# Knowledge Base

This directory contains the source documents for the educational standards that the AI model will use as its compliance knowledge base. It includes:

- Federal standards (e.g., Head Start ELOF)
- State-specific standards (e.g., Missouri MELS and MLS)

The documents in this directory will be processed, tokenized, and indexed into a vector database to be used by the Retrieval-Augmented Generation (RAG) engine.
